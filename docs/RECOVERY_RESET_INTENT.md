# 从机清网意图 journal

状态：2026-10-27，持久化基础代码，尚未接入运行时。`include/recovery_reset_intent.h` 与从机工程保持一致；它不提供 GATT 命令、不调用 SDK、不激活绑定，也不能启用泵阀。

`ResetIntentStore` 的职责是将清网边界分成 `Prepared`、`ResetCommitted`、`MeshCleared`、`Cancelled`。准备回执不能当作清网提交；调用方只有在 `commit` 返回 `Applied`、控制锁仍持有且全部运行时检查有效时，才可能继续执行清网。`Existing` 仅表示查询到了相同操作，必须读取实际阶段并对账，不能再次盲调 SDK。任何存储写入或读回结果不确定，当前实例进入 `Fault`，不能继续提交；重启只加载 selector 选中的记录，不提升较新的孤立 slot。

## 接入时必须满足的前提

当前类只是内部存储原语，不构成请求授权。后续协调器必须负责：

1. 验证恢复会话、当前凭证版本、目标主机信任、新鲜准备回执、时限与操作意图。回执签名有效不等于持有从机恢复权限。
2. 在唯一控制任务中锁住所有新任务与本地开阀入口，再获取实时状态。七项检查缺一即拒绝新的准备/提交：准入已锁、任务空闲、软件输出关闭、本地按住已释放、无维护许可、满足流量静默策略、旧发送与回调已静止。布尔快照必须由该任务产生，不能从 APP 输入。
3. 在保存意图前，将本次 OOB 等秘密材料写入独立受保护记录，并验证内容、承诺值和引用对应。journal 只保存 `attemptSecretRef`，不保存 OOB 或恢复密钥。存储原语及其尚未实现的退休/重试边界见 [RECOVERY_ATTEMPT_SECRET.md](RECOVERY_ATTEMPT_SECRET.md)。
4. 从已提交绑定或经校验的迁移记录取得 `minGeneration`，不能在 journal 缺失时默认旧绑定代际为零。仅新准备消耗下一代际；取消保留高水位，不能回退或溢出复用。
5. `Prepared` 取消前确认旧 SDK 网络摘要仍一致；清网提交后禁止取消回旧网。重启后重新认证、检查实际 SDK 状态和秘密引用，再续办。相对 uptime 时限不能跨重启直接复用。
6. `MeshCleared` 只能在 SDK 实际未配网且安全检查通过后持久化；丢 ACK、断线、写 GATT 成功均不算证据。

当前不支持重新武装尝试、完成新绑定、运行资格、主机预留和归档。这些须由后续完整事务增加；不能据此开放恢复 UI。新绑定仍必须通过独立 AppKey、V7 域隔离和双向验证，最后进入待启用。

## 记录 schema

固定 408 字节，所有整数小端。通过现有 A/B `Journal` 保存，建议后续使用从机专用命名空间，不能与凭证或 Mesh 命名空间复用。

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 4 | magic `0x31545250` |
| 4 | 2 | 版本 1 |
| 6 | 2 | 长度 408 |
| 8 | 1 | 阶段 1–4 |
| 9 | 7 | 保留，必须为 0 |
| 16 | 16 | 从机物理 UUID |
| 32 | 4 | credential_epoch |
| 36 | 4 | 保留，必须为 0 |
| 40 | 8 | 已预留的 generation 高水位，等于回执 generation |
| 48 | 32 | 旧 SDK 网络状态摘要，具体摘要算法待 SDK 适配冻结 |
| 80 | 16 | 已持久化秘密材料引用 |
| 96 | 176 | 规范编码的主机准备回执 |
| 272 | 65 | 本次目标主机公钥 |
| 337 | 64 | 准备回执 low-S 签名 |
| 401 | 7 | 保留，必须为 0 |

加载时重新验证 schema、物理 UUID、凭证版本、generation、回执规范编码、公钥指纹和签名。CRC 用于偶发损坏检测，不承担恶意 Flash 修改保护；既有物理安全边界保持方案定义。

记录底层包含两个最大 432 字节 slot 和一个 24 字节 selector（当前协议净数据 888 字节），不包含 NVS 条目、页面、命名空间和垃圾回收开销。这个数值不能代替 64 KiB NVS 最坏容量验收。

## 本地验证

`tools/run_recovery_tests.py` 使用固定 SDK 的真实 mbedTLS，验证主从共享代码一致性。新增测试覆盖四种阶段写入的 32 个掉电/模糊提交边界、456 个持久化字节损坏、带有效 CRC 的错误 schema/证明、七项安全前提、冲突及幂等请求、取消代际高水位和 UINT64_MAX 溢出拒绝。

这些是模拟存储故障；真实 NVS 满、设备掉电、GPIO、Mesh 回调和并发准入仍须实机验证。
