# 主从固件运行日志

默认 INFO 构建只保留启动身份与配置、配网和手机连接事件、泵阀输出变化、主机任务阶段与结束原因、警告和错误。从机保留霍尔启动、每秒采样、结束和手动查询快照，用于继续排查零脉冲问题；霍尔中断内不打印日志。

以下明细降为 DEBUG，默认构建不输出，也不执行其日志格式化与发送：

- 主从逐包 `mesh_tx` 发送跟踪。
- 主机 `cap_rx`、`lease_rx`、`command_rx`、`closed_rx` 回执明细。
- 主机 `start_guard`、`start_proof` 启动过程明细。
- 每 10 秒的 `mesh_diag` 指标与 `runtime_mem` 内存、栈余量。

Mesh 故障计数仍每 10 秒检查一次，只有计数变化时以 WARN 输出 `MESH_STATE` 和首个/最近故障证据，避免持续重复相同故障。`mesh-diag` 和 `local` 手动查询继续可用。发送跟踪队列仍正常排空，故障快照、发送完成处理和协议消息不依赖日志级别。

需要抓逐包链路诊断时，重新构建启用 DEBUG 的固件：将 ESP-IDF 的默认日志级别和最大日志级别都设置为 DEBUG（4），确认生成的 `sdkconfig.h` 后编译；仅调整串口监视器过滤器或运行时日志级别不能恢复已被编译排除的明细。详细日志只在排查期间开启。

默认日志无法用于统计每包 SAR 延迟；分析工具缺少 `mesh_tx` 样本时，不能据此判断丢包或发送完成回调缺失。
